# Architecture decisions

Why this repository is shaped the way it is. One file per decision, each recording the option that
was rejected as well as the one that was taken. A decision that changes gets a new record
superseding the old one, never an edit to it — so read this index before acting on an old record.

A record explains a rule; it does not carry it. `AGENTS.md` holds every operative rule, and where
a record and `AGENTS.md` differ, `AGENTS.md` is what the repository does.
